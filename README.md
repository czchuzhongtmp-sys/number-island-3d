# 🏝️ 数数小岛 V2 · 3D 数学启蒙游戏

给 **4 岁左右**孩子的 10 以内数与加减法启蒙游戏。孩子和小鸡“豆豆”在一座 3D 小岛上摘苹果、合起来、喂小鸡，在动手玩的过程中理解“数量、变多、变少”。

**▶ 在线玩：** https://czchuzhongtmp-sys.github.io/number-island-3d/ （平板横屏效果最好，记得打开声音）

## 四个游戏
| 游戏 | 学什么 | 怎么玩 |
| --- | --- | --- |
| 🍎 摘苹果 | 点数、按数取物、基数原则 | 按要求摘 N 个苹果放进托盘；或点一点数托盘里有几个 |
| 🧺 合起来 | 加法 = 合并、接着数（counting on） | 把篮子里的黄苹果一个个放进托盘，从红苹果的数量接着数 |
| 🐥 喂小鸡 | 减法 = 拿走 | 喂豆豆吃掉几个，看看托盘里还剩几个（被吃掉的位置会留下淡淡的影子） |
| 🌈 小冒险 | 综合 + 速视（看一眼就知道几个） | 随机出现以上任务，以及“看一眼”盖布游戏 |

## 依据的教学理念
- **CPA 教学法（具体→图像→抽象，新加坡数学）**：3D 苹果 → 十格框/点阵 → 算式 `3 + 2 = 5`。
- **学习路径理论（Clements & Sarama, Learning Trajectories）**：点数 → 按数取物 → 合并/接着数 → 拿走，符合 4 岁孩子的发展顺序。
- **十格框（Ten-frame）与速视（Subitizing）**：托盘本身就是十格框，帮助形成“5 和几”的数感。
- **最近发展区（ZPD）+ 支架式教学**：每项技能独立的自适应难度（3–10）；答错先一起数，再给提示，不会卡住。
- **成长型思维反馈（Dweck）**：表扬努力和方法，不说“错”，没有扣分、计时、失败画面。
- **多感官与双重编码**：语音朗读（不识字也能玩）、数字越大音越高、数字 + 点阵对应。
- **自我决定理论**：每完成一题小岛长出一朵花、出现蝴蝶，用“建设小岛”带来内在动机。
- **4 岁儿童交互设计**：只需点击、不用拖拽；超大点击区域；6 秒没操作会出现小手指提示；每轮 3–8 题；到时提醒休息。

## 技术
- 纯前端：HTML + CSS + JavaScript（ES Modules），3D 渲染使用 [three.js](https://threejs.org)（MIT，已内置在 `lib/`，无需联网 CDN）。
- 所有模型均为代码生成的低多边形原创造型，音效为 Web Audio 实时合成，语音使用浏览器自带的中文 TTS。
- 进度保存在本机浏览器（localStorage），不收集任何数据。

## 本地运行
ES Modules 需要通过网页服务器打开：
```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```
